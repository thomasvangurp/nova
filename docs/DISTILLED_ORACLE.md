# Diffusion-free Boltz student

## Goal

Use Boltz as a high-fidelity teacher for only the small, informative fraction of a candidate pool. A target-conditioned student ranks the whole pool, estimates uncertainty, and escalates promising or out-of-distribution molecules to Boltz. It never replaces the exact scorer in validation or reporting.

```text
cached protein/MSA representation + ligand graph
                    |
       interaction representation on GPU
                    |
       objective mean + uncertainty
                    |
      acquisition: high mean + uncertain
                    |
          bounded Boltz teacher batch
                    |
      exact constraint-aware submission
```

## Scope and transfer

P40261 is the first competition adapter, not the definition of the model. The shared base is trained across proteins. Each observation is a `(protein sequence, ligand, measurement)` tuple, and target and anti-target terms are evaluated separately before the competition objective is composed.

There are two complementary student paths:

1. `compound_miner.distilled.DistilledOracle` is an independent molecular-graph and cached-ESM model. It can pretrain on public ChEMBL/BindingDB affinities and then fine-tune on Boltz objective labels.
2. `compound_miner.interaction_student.RidgeInteractionEnsemble` calibrates the frozen, target-conditioned 400-dimensional PSICHIC interaction fingerprint to Boltz. This is the stronger bootstrap when PSICHIC is available; its ensemble variance supplies a first uncertainty estimate.

The prepared public corpus contains 214,938 usable interactions from 4,937 proteins. It is deterministically capped at 64 ligands per protein so the universal representation is not dominated by a few popular targets.

Historical competition result lists must not be used as molecule seeds. Public affinity data and newly generated, rules-compliant teacher labels train the model; evaluation candidate pools must be generated by the permitted reaction/search process.

## Current evidence

The first prototype benchmark uses 131 P40261 molecules with Boltz labels. A whole-Murcko-scaffold split produced 103 training and 28 validation molecules.

| Model | Validation Spearman | Top-10 recall at Boltz budget 20/28 |
|---|---:|---:|
| Raw PSICHIC scalar | 0.178 | 0.60 |
| PSICHIC fingerprint + ridge/leverage ensemble | 0.678 | 1.00 |

This is architectural evidence only. The holdout is small and a 71% Boltz escalation budget does not establish the intended 1% cascade. Adding Bayesian-ridge leverage to bootstrap variance improved uncertainty/error Spearman from 0.063 to 0.213, but this is still not a trustworthy out-of-distribution gate.

Most current labels use the reduced Boltz configuration. On the 15 molecules
also scored with validator-matched settings, reduced versus exact scores had
Spearman 0.596 and MAE 0.0146. Reduced labels are therefore useful for broad
pretraining but cannot be treated as ground truth. Exact labels must anchor
calibration and every frozen promotion holdout.

A deliberately small universal-base smoke train used 5,000 balanced BindingDB
rows, held out 1,053 rows by entire protein target, and ran one public pretrain
epoch. It reached target-holdout affinity Spearman 0.313 (MAE 1.60 pAffinity).
The macro within-target Spearman was only 0.114 over 34 evaluable targets, and
its MAE was worse than the training-set global-mean baseline (1.60 versus 1.22).
This confirms that the cross-target path is wired correctly but explicitly
rejects this smoke checkpoint as a useful oracle. It needs the full corpus,
cached ESM features, and a proper multi-epoch GPU train. On a four-worker Mac
CPU the complete smoke train took 106 seconds, predominantly RDKit packing
rather than model inference.

On RTX 4090, the independently timed warmed PSICHIC feature path processed 131 molecules at 98.4 molecules/s, including CPU ligand featurization. The warmed reduced Boltz path processed about 0.41 molecules/s on the matched workload. The representation path is therefore about 239 times faster before the negligible adapter head. The uncertainty-aware adapter alone exceeded 175,000 molecules/s on CPU for this small batch.

## Accuracy gates

Do not promote the student on random-row metrics or training-set diagnostics. Promotion requires all of the following on frozen, unseen, legally generated candidate pools:

1. Split by molecular scaffold, reagent/component identity, and collection time. For transfer claims, also hold out entire protein targets.
2. Report MAE and Spearman, but treat pairwise ranking and top-tail recovery as the primary model metrics.
3. At the actual 1% teacher budget, recover at least 90% of the true top-20 and retain at least 98% of the best feasible submission objective after exact uniqueness, similarity, and entropy selection.
4. Show calibrated uncertainty: high-uncertainty examples must contain a materially larger fraction of large errors and missed winners than low-uncertainty examples.
5. Beat the incumbent end-to-end on multiple frozen rounds or targets. Measure candidate generation, student inference, Boltz escalation, and final assembly separately so startup cannot masquerade as an inference gain.
6. Keep an exploration reserve for out-of-distribution candidates. A high-mean-only cascade can silently lock into a false basin.

The decisive quantity is constrained decision regret:

```text
best feasible objective using all Boltz labels
  - feasible objective using only the cascade's Boltz labels
```

## Data plan

1. Pretrain the shared graph/protein base on the balanced BindingDB corpus and public ChEMBL rows.
2. Generate broad candidates across every permitted reaction and across score, uncertainty, and diversity strata. Do not label only the current proxy's top tail.
3. Label the initial set with Boltz. Freeze a scaffold/component/time holdout before fitting adapters.
4. Run active-learning rounds: high predicted mean, high epistemic uncertainty, and structurally underrepresented basins each receive a fixed quota.
5. Continue until the 1% cascade gates stabilize across at least three independent candidate pools and target holdouts.

The 131-label prototype is too small for the 1% gate. A top-20 recall gate at a
1% budget is not even arithmetically possible below 2,000 labelled pool members.
A useful first checkpoint is therefore 2,000–5,000 diverse teacher labels;
broader all-purpose fidelity will require substantially more labels distributed
across proteins, while a competition-frontier adapter can succeed with fewer if
active learning concentrates labels around the reachable frontier.

## GPU deployment

GPU is preferred for the interaction encoder and student when the candidate batch is large. Proteins and anti-targets remain resident; ligands are packed into fixed-size buckets; CPU graph construction overlaps GPU inference. The light ridge head is not itself GPU-bound and can remain on CPU for small batches.

Keep a CPU path for small workloads and CI. Benchmark warmed sustained throughput with at least several thousand molecules. Single-batch results are startup-dominated and are not acceptable evidence.

## Commands

Prepare a target-balanced public corpus:

```bash
python tools/distill_oracle.py prepare-bindingdb \
  --input BindingDB_All.tsv \
  --output data/public/BindingDB_balanced64.csv.gz \
  --maximum-per-target 64 --minimum-per-target 8
```

Train the graph/ESM ensemble:

```bash
python tools/distill_oracle.py train \
  --public-csv data/public/BindingDB_balanced64.csv.gz \
  --boltz-json artifacts/boltz/teacher.json \
  --output models/distilled --device cuda
```

Extract frozen PSICHIC interaction features and fit the adapter:

```bash
python tools/extract_psichic_features.py \
  --psichic-root PSICHIC --records-json artifacts/boltz/teacher.json \
  --target P40261 --output artifacts/student/p40261_features.npz

python tools/train_interaction_student.py \
  --features artifacts/student/p40261_features.npz \
  --records-json artifacts/boltz/teacher.json \
  --output models/interaction_student/p40261.npz --device cuda

python tools/select_interaction_student.py \
  --model models/interaction_student/p40261.npz \
  --features artifacts/student/current_pool.npz \
  --output artifacts/student/escalate_to_boltz.json \
  --fraction 0.01 --minimum 100 --uncertainty-fraction 0.25
```

Evaluate the bounded decision cascade with the independent graph student:

```bash
python tools/distill_oracle.py cascade-evaluate \
  --model models/distilled --boltz-json artifacts/boltz/holdout.json \
  --fraction 0.01 --minimum 100 --submission-count 20 --device cuda
```
