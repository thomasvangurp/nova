# V3 depth-12 controls

Added before the V3 run after V2 showed that delaying the first prune to six
or seven repeats was strongest, but its survivors had only nine or ten total
current-epoch observations. V3 adds two same-budget arms that preserve the live
depth of twelve observations for survivors: 6 broad + 5 finalist rounds and 7
broad + 4 finalist rounds. This tests whether delayed pruning can improve the
allocation without weakening the qualification depth. No prior arm or outcome
definition changed.
